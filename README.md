# 迈克尔·杰克逊：人生选择（全新实现）

基于 `GDD.md`（v0.6）**严格重建**的文字冒险 / 人生模拟游戏。旧版单文件原型已归档至 `archive/`。

## 运行方式
直接双击 `index.html` 即可在浏览器运行（采用经典脚本加载，无需构建工具 / 本地服务器）。
> 若浏览器对 `file://` 下的 `localStorage` 有限制，可用任意静态服务器，例如：
> `python -m http.server` 后访问 `http://localhost:8000`。

## 构建分发（可选，M2）
源码保持「经典脚本 + 双击即运行」不变；如需一个便于部署的单文件产物，可用 Vite 打包：

```bash
npm install      # 安装 vite 与 vite-plugin-singlefile（仅开发依赖）
npm run build    # 产出 dist/index.html 单一文件（JS/CSS 全部内联）
```

`dist/index.html` 已内联全部脚本与样式，**双击即可运行**，可直接托管到任意静态空间。

## 架构（模块化）
```
index.html              入口，按依赖顺序加载脚本
css/style.css           暗金复古主题、四区布局、响应式
js/config.js            全局配置：初始属性 / 标志 / 元路线 / 14 结局（含 1 隐藏终极 + 1 续章结局）
js/events.js            事件数据（数据驱动，对齐 GDD 6.4 全部节点 + 变体事件）
js/state.js             游戏状态 + Economy 子系统（净资产/债务双轨）
js/engine.js            规则引擎 / 效应应用 / 结局解析 / 事件流 / 变体插入 / 存档
js/ui.js                视图与用户流程（引导 / 状态栏 / 事件卡 / 结局）
```

## 对齐 GDD 的关键设计
- **核心玩法**：六维属性（健康/声誉/财富/家庭/艺术/压力，均 0–100）。
- **Economy 双轨**：大额金钱走 `netWorth/debt`（万元），修复旧原型“财富 clamp 到 0”导致 3 种结局不可达的 bug。
- **结局系统**：严格按 GDD 7.2 的 14 结局（含 1 隐藏终极 + 1 续章结局）+ 优先级规则表（含元路线破平次序、survived2009 续章收束）。
- **元路线**：艺术家 / 慈善家 / 商业巨擘 / 隐士，隐藏计数由选择累积。
- **变体事件**：GDD 5.6 的可能性系统，按概率 + 年份窗口在章节间插入。
- **规则引擎**：压力→健康联动 `health -= floor(stress/20)`（GDD 8.1）。
- **存档**：`localStorage` 自动存档（含当前事件 id），刷新可续玩。
- **中性叙述**：法律相关事件采用程序化 / 事实化表述，不预设有罪或无罪。
- **响应式**：CSS Grid + 媒体查询，移动端两列属性、桌面三列，适配不同设备。
